\## \[0.1.0] - 2026-10-20



\### Added

\- Logistic regression classifier for the Iris dataset (accuracy 1.00 on a 30-sample test set).

\- Confusion matrix chart saved to `docs/confusion\_matrix.png`.

\- `iris-train` command via `pyproject.toml`.

\- Unit tests with pytest.

\- GitHub Actions CI running Ruff and pytest on Python 3.10–3.12.
